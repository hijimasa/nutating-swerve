# MuJoCoによる偏心クランク式操舵の検証結果

検証日：2026-10-13。MuJoCo 3.3.7、Python 3.12。寸法・質量・摩擦は仮定値で、機構の初期検討用モデルです。

## 結論

受動２軸ジンバルに支持された車輪・モーターの後端を偏心クランクで動かす構成は、モデル上で連続操舵できます。車輪駆動と同時に10周操舵でき、ジンバルの２軸は有限範囲を往復し、モーター本体は初期姿勢へ復帰しました。回転位相を折り返す処理や、動力学実行中に受動関節の姿勢を強制する処理は使用していません。

ただし、今回のようにジンバル支点と車輪中心を車軸上に置いた一定傾斜の構成では、駆動と操舵による瞬間的な水平速度が同一直線上になります。無限操舵機構の成立は確認しましたが、ホロノミックなアクティブキャスターとしてのランク２の運動は実現していません。

## 動力学の結果

| 計測項目 | 接地なし・10周 | 接地あり・２周 |
| --- | ---: | ---: |
| 操舵周期 | 2秒／周 | 4秒／周 |
| 車輪速度指令 | 3 rad/s | 3 rad/s |
| 時間刻み | 1 ms | 1 ms |
| 最大閉リンク残差 | 0.007224 mm | 0.001186 mm |
| 車軸傾斜の範囲 | 45.0000〜45.0034° | 44.9996〜45.0005° |
| 本体姿勢の最終復帰誤差 | 約0.000002° | 約0.000317° |
| 最大操舵トルクの絶対値 | 約0.0107 N·m | 約0.0441 N·m |
| 最大車輪駆動トルクの絶対値 | 約0.00463 N·m | 約0.0695 N·m |
| 解析区間の接触率 | 対象外 | 100% |
| 解析区間の平均接触点滑り速度 | 対象外 | 約2.52 mm/s |
| MuJoCoの警告 | なし | なし |

接地試験の解析区間は、始動と停止の各ランプ区間を除いた1秒〜8秒です。車体の並進は自由ですが、姿勢は理想的な治具で固定されています。自由に姿勢が変わる車両の走行安定性は、この試験では評価していません。

操舵を固定した別の直進試験では、5.5秒で約0.975 m移動しました。車輪速度は単純な比例速度制御のため、接地時には指令3 rad/sに対して平均約2.70 rad/sでした。操舵停止後も車輪速度指令は保持されるため、周回試験の軌跡の末尾は直線になります。

## 数値設定への依存

接触の時間定数を4 msとした初期設定では、微小な接触の断続が発生しました。最終モデルでは15 msとし、柔らかい接触の近似で接触を安定させています。これは実タイヤの材料特性を同定した設定ではありません。

最終モデルで時間刻みを1 msから0.5 msに半減した場合、接地試験の最終水平位置の差は約0.0550 mm、平均滑り速度は2.5190 mm/sから2.5186 mm/sでした。位置軌跡と平均滑りについては、この２つの刻みでほぼ一致しました。拘束力のピークや材料特性の収束までは評価していません。

## 機構の幾何検証

傾斜30°・45°・60°について、操舵１周を181点で確認しました。各位相で、モーター後端接続点とクランク先端が一致し、１周後の本体姿勢が初期姿勢に戻りました。

ジンバル中心を原点、車軸方向を `a`、後端までの長さを `L` とすれば、後端は `L a` です。傾斜 `theta` を固定すると、その軌跡は半径 `L sin(theta)`、高さ `L cos(theta)` の円になります。２軸ジンバルは各軸の有限な往復でこの軌跡を追従できます。

この姿勢の周期性は、ケーブルのねじれが周回ごとに蓄積しない配置を作れる根拠になります。ただし、ケーブルそのものはモデルに含めていません。実配線の絡まり、他部品との干渉、最低曲げ半径、屈曲寿命の確認は別途必要です。

## 瞬間的な全方向移動の検証

理想円柱の最低接触点で、MuJoCoの点速度ヤコビアンから、次の２入力が作る水平速度を計算しました。

- 車輪の相対回転速度１ rad/s。
- 操舵クランク１ rad/sと、それに幾何的に追従する受動ジンバルの角速度。

傾斜30°・45°・60°の全位相において、2×2の速度変換行列の第２／第１特異値比は約4×10^-16以下でした。すなわち、今回の構成ではランク１です。

この結果は、向きを操舵してから任意方向へ走れることを否定しません。一方、現在の操舵姿勢のまま２入力を組み合わせて任意の平面速度を作ることはできません。真のアクティブキャスターを狙う場合は、支点と車輪・接地点の配置を再設計し、同じ速度ヤコビアンの検証を行う必要があります。

## 未検証事項

- ジンバル・クランク・支持部・車輪の自己干渉。
- ケーブルの物理的な変形、絡まり、屈曲寿命。
- 軸受の隙間、摩擦、クランク接続部の許容首振り角。
- 製造誤差による過拘束と組立調整。
- タイヤの弾性、接触面積、実際の摩擦特性。
- 自由姿勢の車体、複数モジュール、段差、床面の凹凸。
- デファレンシャル式との製作費・耐久性・効率の実測比較。
